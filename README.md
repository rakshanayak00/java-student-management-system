# Java Student Management System

A menu-driven Student Management System built using Core Java.
## Features
- Add student
- View students
- Search student by ID
- Delete student by ID
- Menu-driven console application
## Technologies Used
- Java
- ArrayList
- Scanner
## Project Structure
- Student.java – Model class
- StudentManager.java – Main application logic
## How to Run
Compile:
javac Student.java StudentManager.java
Run:
java StudentManager
## Learning Outcome
This project helped me strengthen Core Java concepts like OOP, collections, and control flow.
